# Consulta de CEP - Correio Virtual 2000

Projeto desenvolvido para a disciplina de Programação para Web, com o tema de consulta de endereço através do CEP, usando a API do ViaCEP.

O visual do site segue um estilo Y2K, inspirado nas interfaces do Windows e nos sites do início dos anos 2000.

## Funcionalidades

- Consulta de endereço (rua, bairro, cidade e estado) a partir de um CEP
- Indicação visual de carregamento durante a busca
- Tratamento de CEP inválido ou não encontrado
- Exibição do endereço num mapa (Google Maps)
- Layout responsivo

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- API ViaCEP (https://viacep.com.br/)

## Como executar

1. Baixe ou clone este repositório
2. Abra o arquivo `HTML.html` em um navegador
